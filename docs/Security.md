# 服务器硬盘管理工具 安全设计

## 定位与威胁模型

“服务器硬盘管理工具”（ServerDiskManagementTool）是单用户、本地运行的桌面应用。本地数据在本机 SQLite；远端通过系统 OpenSSH 连接。威胁模型包括：

- 远端主机被冒充或主机密钥变化（中间人）。
- 恶意/异常远端输出破坏解析或诱导执行。
- 前端被篡改后传入任意命令或路径。
- 本机凭据泄露到数据库、日志、argv 或导出文件。
- 批量操作误伤生产服务器。

不把应用视为多租户、服务器端服务或沙箱边界。

## 主机密钥

- 始终使用 `StrictHostKeyChecking=yes` 和应用私有 `known_hosts`。
- 未知主机：`ssh-keyscan` 获取候选密钥，展示 SHA256 指纹；用户确认后写入。`pendingTrustId` 绑定当时扫描结果，前端不能替换指纹。
- 已信任主机的密钥变化：阻断连接，并在服务器状态/设置中提示。需先删除旧信任，确认服务器确实轮换密钥后再重新确认。
- 不使用 `accept-new` 静默信任；不自动覆盖旧密钥。
- `known_hosts` 路径包含空格时，OpenSSH `UserKnownHostsFile` 选项会加引号；已在集成测试中验证。

## 命令执行

- 所有远端脚本随包携带（`probe_v1.sh`、`usage_v1.sh`、`metrics_v1.sh`、`recommend_v1.sh`、`cleanup_*_v1.sh`），不下载、不拼接用户命令。
- 脚本通过 stdin 发送；参数以 `sh -s -- '<arg>'` 传递，使用 POSIX 单引号转义；拒绝 NUL、换行、相对路径和 `..`。
- 前端只传服务器 ID、扫描 ID、节点 ID、模板 ID、计划 ID/令牌；后端从数据库解析真实路径并校验。
- 清理执行只走固定 case 分支；没有 `eval`，没有自由 `rm`。
- 输出上限 8 MB；超限/超时/取消会终止子进程并返回明确错误。
- 失败被识别为失败；SSH 中断不当作成功。

## 凭据

- 密码与私钥口令只保存在系统凭据存储（macOS 钥匙串 / Windows 凭据管理器，`keyring`），数据库仅存引用；不记住时只放内存。
- macOS 通过临时 `SSH_ASKPASS` 脚本读取 0600 临时文件；Windows 通过应用自身可执行文件的 askpass 分支读取临时文件（`NOVA_RACK_ASKPASS` + `NOVA_RACK_ASKPASS_SECRET`）。秘密不出现在 argv；命令结束后删除临时目录，应用启动时清理残留。
- 支持 agent、私钥、加密私钥、密码；不支持 sudo 密码。
- 不记录密码/口令/私钥内容；导出不含秘密。

## 权限与 sudo

- 只使用 `sudo -n`。没有免密 sudo 时，系统级模板在执行前检查阶段失败，不弹出密码提示。
- 推荐给专用 SSH 用户配置最小化 NOPASSWD 命令；见 [SSH-Setup.md](SSH-Setup.md)。不建议给完整 `ALL` 权限用于生产。
- 只读巡检不需要 sudo；无 sudo 时部分目录/模板受限，UI 标记为部分结果。

## 写操作安全

- 计划 5 分钟过期，一次性令牌；默认不勾选任何写项。
- 前端不允许“筛选结果全选”直接写；需要在计划中确认主机、路径、命令与不可逆项。
- 执行前重检：路径存在、非符号链接、文件大小、挂载非只读、命令可用。
- 模板回收不可逆；隔离区可恢复；永久删除默认关闭，仅普通文件，需输入 `DELETE`。
- 每个写任务只允许每主机一个；全局并发默认 2；失败停止该主机后续项。
- 执行前后读取 `df` 计算实际释放；失败/部分失败保持失败状态；审计记录命令、结果与错误。

## 数据与文件权限

- macOS：应用数据目录 0700；SQLite、known_hosts 0600。
- Windows：数据放在 `%LOCALAPPDATA%\com.novarack.desktop`，权限继承当前用户配置目录的 ACL；不额外改写 DACL，其他标准用户不可读，管理员/系统仍可访问。askpass 临时文件位于用户临时目录，命令结束后删除。
- SQLite 只存服务器元数据、快照、任务、分析结果、告警、计划、隔离记录、审计；不含秘密。
- 导出 CSV/JSON 包含主机名/路径，属用户主动操作；没有遥测、云同步或自动上传。

## 已知限制

- 主机密钥首次信任仍需用户带外核对指纹；应用无法替代运维流程。
- 无免密 sudo 时，模板回收不可用；仍可只读分析。
- 清理命令依赖远端工具（apt/dnf/yum/pacman/apk、journalctl、docker、GNU find 等）；缺失时在执行前检查失败。
- 清理执行不具备事务回滚；部分操作天然不可逆（journal、Docker prune、永久删除）。
- 本地构建未签名/公证；Windows 安装包也未签名。正式发布前需补齐 macOS Developer ID/公证和 Windows 代码签名。
